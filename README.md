# HA OpenIMPRES Card

A planned Home Assistant custom dashboard card for OpenIMPRES.

This repository is the starting point for card development. The card implementation,
Home Assistant entity mappings, configuration, and installation instructions will
be added once the desired behaviour and data source are defined.

The protocol research and passive capture firmware live in
[OpenIMPRES](https://github.com/rodgrech/OpenIMPRES).
